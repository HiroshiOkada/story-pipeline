# 詳細仕様作成

## ゴール

`docs/specification.md` で確定したプロダクト仕様を変更せず、Story Pipeline の初期実装に必要なデータ形式、CLI の振る舞い、外部 API 連携、Git 操作、安全性、テンプレートを実装可能な粒度で定義する。

## 完了条件

- 実装者が追加のプロダクト判断をせずに主要コンポーネントを実装できる。
- 状態ファイルと要求別実行記録の構造、制約、遷移が明記されている。
- 各 CLI サブコマンドの入出力、終了コード、副作用、失敗時動作が明記されている。
- Git 操作、管理対象ファイル、秘密情報、大規模変更の安全規則が明記されている。
- LLM 呼び出し、構造化応答、再試行、フォールバック、呼び出し上限が明記されている。
- scaffold、設定、要求、報告の各テンプレートが明記されている。
- 詳細仕様全体が `docs/specification.md` と矛盾しないことを確認している。

## 対象外

- CLI 本体の実装
- 単体テストおよび統合テストの実装
- `docs/specification.md` で確定済みのプロダクト方針の変更
- 初期対象外とされた画像、音声、出版形式の仕様追加
