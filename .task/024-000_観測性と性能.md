# フェーズ024: 観測性と性能

## ゴール

LLM 通信から run 終了処理までを秘密値なしで追跡でき、長時間処理中の生存と、障害の発生階層・再試行可否・利用量・待機時間を実行記録から判定できるようにする。

## 完了条件

- 論理呼び出しと transport 試行を分離し、モデル、再試行、待機、フォールバック、打ち切り、利用量を run JSON に記録できる。
- provider が usage を返さない場合は推測値で埋めず `null` を保存する。
- 非ストリーミング通信が長時間継続する場合、秘密値を含まない heartbeat を標準エラーに出力する。
- workflow、実行終了処理、Git、lock、割り込みを別の component と incident ID で記録できる。
- run 内の集計値が詳細記録と一致し、再開時の無駄な knowledge 再生成数を報告できる。
- API に依存しない自動テストと配布物統合確認が成功する。
