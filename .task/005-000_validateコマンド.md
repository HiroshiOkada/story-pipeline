# validate コマンド

## ゴール

作品、設定、状態、実行記録、Git 作業ツリーの整合性を副作用なく網羅的に検査し、機械判読可能な問題コードと安全な修正対象を提示する `validate` コマンドを実装する。

## 完了条件

- 設定、状態、全実行記録のスキーマと参照を検証できる。
- 要求、報告、成果物、採番、phase、記録済みハッシュの対応を検証できる。
- 管理対象パスの種類、作品ルート外リンク、Git 状態、追跡状態を検証できる。
- `.gitignore` の必須除外と必要な API キー環境変数の存在を検証できる。
- 問題を規定形式で可能な限り列挙し、エラー有無に応じた終了コードを返せる。
- ファイル、Git、ロック、ネットワークを変更・使用せず動作する。
- 正常系と代表的な異常系を自動テストで確認できる。
