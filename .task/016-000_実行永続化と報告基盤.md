# 実行永続化と報告基盤の作業目標

## ゴール

`run` コマンドの統合に先立ち、要求ごとの実行記録と作品状態を安全に更新し、実行結果から決定的な報告を生成し、次要求テンプレートを非破壊に作成できる基盤を実装する。

## 完了条件

- state/run JSON を UTF-8、インデント2、末尾改行付きで同一ディレクトリへ原子的に保存できる。
- 新規実行の開始、工程状態の更新、終了状態への確定を仕様どおり表現できる。
- run を先、state を後の順序で保存し、active/last request の状態遷移を一貫して更新できる。
- 実行記録と採用結果を情報源として、必須見出しを備えた報告を決定的に生成できる。
- 既存ファイルを上書きせず、次番号の要求テンプレートを未追跡候補として作成できる。
- 単体テストと API を使わない統合テストが成功する。

## 対象外

- `run` コマンド全体の前提検査、LLM 呼び出し、各制作 workflow の振り分け
- Git 開始時・終了時コミットとの最終接続
- 中断済み実行の依存関係を考慮した工程単位の自動再開
- OpenRouter を使う統合テスト
