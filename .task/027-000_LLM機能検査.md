# LLM 機能検査

## 作業目標

設定された LLM API が Story Pipeline の実行に最低限必要な Chat Completions 機能を提供するか、作品や実行状態を変更せずに明示的に検査できる専用サブコマンドを提供する。

## 完了条件

- 利用者が専用サブコマンドを明示的に実行した場合だけ LLM API を呼び出す。
- 実際に利用するモデルについて、通常応答と構造化 JSON 応答を検査できる。
- 成功・失敗を秘密情報を含まない診断結果と終了コードで確認できる。
- 単体テストと OpenRouter を利用する統合確認で動作を検証する。
- CLI 仕様と利用者向け文書に使用方法と副作用を記載する。
