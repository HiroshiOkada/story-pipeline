# フェーズ026: エンドユーザー取扱説明書

## ゴール

Story Pipeline を初めて利用するエンドユーザーが、導入、作品の初期化、設定、要求の記述、制作の実行、成果物の確認、追加要求、停止時の復旧までを安全に自力で行える、実装と整合した詳しい取扱説明書を提供する。

## 完了条件

- 導入前の準備から作品完成までの標準的な利用手順が順序立てて説明されている。
- 設定項目、要求・報告・作品ファイル、各 CLI コマンドと終了コードが利用者向けに説明されている。
- `awaiting_human`、`failed`、ロック、Git 差分、検証エラー、旧状態移行の安全な対処が説明されている。
- 記載したコマンド、既定値、ファイル構成が実装およびテストと照合されている。
- README から取扱説明書へ到達できる。
