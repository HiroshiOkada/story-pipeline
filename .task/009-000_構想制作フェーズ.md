# フェーズ009: 構想制作フェーズ

## ゴール

構造化済みの要求と作業範囲から `concept.md` の候補を生成し、機械検査、構造化評価、必要な改稿を経て、安全に採用できる最良候補を決定する制作フェーズを実装する。

## 完了条件

- 要求、必須条件、禁止事項、採用済みコンテキストを優先順位と境界が明瞭なメッセージへ構成できる。
- `concept.md` の全必須見出し、空内容、テンプレートコメント、不要な fence を決定的に検査できる。
- reviewer の評価 JSON を厳格に検証し、必須条件違反または整合性 error のある候補を採用しない。
- 呼び出し上限内で生成、評価、改稿を行い、評価済み候補から仕様どおり最良版を決定できる。
- 人間判断が必要な評価と、上限内で解決できない不採用状態を明示的な結果として返せる。
- 単体テスト、API を使わない統合テスト、指定 OpenRouter 構成での構想制作試験が成功する。

## 対象外

- 基礎設定、全体構成、話計画、本文、章・全体改稿の制作
- `run` コマンド全体のオーケストレーション
- state/run JSON の書込み、Git コミット、報告、次要求の作成
- 既存 `concept.md` に対する部分修正要求
