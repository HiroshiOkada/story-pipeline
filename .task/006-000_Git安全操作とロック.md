# フェーズ006: Git 安全操作と実行ロック

## ゴール

`run` コマンドの本処理に先立って利用者の Git 状態を保護し、同時実行を防止できる基盤を実装する。

## 完了条件

- porcelain v2 の結果を安全に解析し、作品ファイルを仕様どおり分類できる。
- Git の事前条件を副作用なく検査し、管理ファイルだけを明示パスで復元できる。
- stage 対象を完全一致で検証し、開始時・終了時コミットを明示パスだけで作成できる。
- 実行ロックを排他的に取得・更新・解放し、安全に stale と判断できないロックを保持する。
- 単体テストと API を使わない統合テストで、安全要件と非破壊性を確認できる。

## 対象外

- LLM API 接続と生成処理
- 要求本文からの追加資料抽出
- `run` コマンド全体のオーケストレーション
- 1,000 行制限と中断再開
