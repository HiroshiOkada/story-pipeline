# フェーズ007: LLM クライアント

## ゴール

OpenAI 互換 Chat Completions API を、安全な認証情報管理、エラー分類、通信再試行、モデルフォールバック、厳格な応答検証とともに利用できる基盤を実装する。

## 完了条件

- provider と model の正規化済み設定から、秘密を URL・body・ログへ含めずリクエストできる。
- HTTP・通信・応答エラーを仕様の分類へ割り当て、許可された場合だけ再試行またはフォールバックできる。
- API キー、認証ヘッダー、秘密を示す URL query を利用者向けエラーから除去できる。
- Markdown と JSON の応答を推測抽出せず厳格に検証できる。
- 各 provider の初期接続確認を、作品ファイルへ副作用を加えず実行できる。
- 単体テスト、模擬API統合テスト、指定された OpenRouter 構成での接続試験が成功する。

## 対象外

- 制作工程固有の system prompt とコンテキスト選択
- 論理呼び出し回数の run JSON への永続化
- 生成成果物の採用と作品ファイルへの書込み
- 1,000 行制限
