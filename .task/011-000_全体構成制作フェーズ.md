# フェーズ011: 全体構成制作フェーズ

## ゴール

採用済みの構想と基礎設定、構造化済みの要求から `plot.md` と直近の制作に必要な `chapters/NNNN.md` を生成し、機械検査、構造化評価、必要な改稿を経て、安全に採用できる全体構成一式を決定する制作フェーズを実装する。

## 完了条件

- 採用済み構想、基礎設定、要求、必須条件、禁止事項を全体構成用の境界が明瞭な生成コンテキストへ構成できる。
- `plot.md` と章計画の必須見出し、空内容、テンプレートコメント、不要な fence、章番号と収録話範囲を決定的に検査できる。
- 開始、主要転換点、クライマックス、結末が因果的に接続し、人物変化と伏線の設置・回収先を追跡可能か構造化評価できる。
- 各章の開始・終了状態、収録話、前後章との接続条件について、成果物間の整合性 error がある候補を採用しない。
- 呼び出し上限内で生成、評価、改稿を行い、`plot.md` と章計画を同一候補から不可分に採用できる。
- 人間判断が必要な評価と、上限内で解決できない不採用状態を明示的な結果として返せる。
- 単体テスト、API を使わない統合テスト、指定 OpenRouter 構成での全体構成制作試験が成功する。

## 対象外

- 話計画、本文、章・全体改稿の制作
- `run` コマンド全体のオーケストレーション
- state/run JSON の書込み、Git コミット、報告、次要求の作成
- 採用済み全体構成に対する部分修正要求
