# 話計画制作フェーズの作業目標

## ゴール

詳細仕様の `episode_planning` フェーズを実装し、現在要求、採用済み作品情報、対象章、直前話の実際の終了状態を踏まえた次の1話の計画を、検証・評価・必要な改稿を経て採用可能な候補として返せるようにする。

## 完了条件

- `episode_plans/NNNN.md` の候補と生成コンテキストに、対象話番号、現在要求、構想、基礎設定、全体構成、対象章、canon、直前の完成話が明示的に対応する。
- 固定見出し、内容の欠落、対象パス、正の目標文字数を決定的に検査できる。
- 開始状態から終了状態への因果、章目的との整合、開示情報、感情変化、伏線、次話への引き、作品規模を構造化評価できる。
- 不採用候補を呼び出し上限内で改稿し、採用可能な最良候補を選べる。
- 人間判断が必要な評価と、上限内で解決できない不採用状態を明示的な結果として返せる。
- 単体テスト、API を使わない統合テスト、指定 OpenRouter 構成での話計画制作試験が成功する。

## 対象外

- 本文、章・全体改稿の制作
- `run` コマンド全体のオーケストレーション
- state/run JSON の書込み、Git コミット、報告、次要求の作成
- 採用済み話計画に対する部分修正要求
