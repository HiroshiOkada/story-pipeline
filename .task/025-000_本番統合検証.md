# フェーズ025: 本番統合検証

## ゴール

公開可能な wheel を使った固定条件の OpenRouter 3作品統合試験を、秘密値を保存せず、事前に定めた費用・呼び出し・時間の停止条件内で実行する。実運用相当の正常終了、状態遷移、Git 整合性、実利用量、heartbeat、checkpoint を検査し、初期リリースの適否を記録する。

## 完了条件

- provider が返す実課金 cost を推測せず論理呼び出しと集計へ記録できる。
- API 呼び出し前に全自動テスト、wheel 統合、秘密値検査が成功する。
- 3作品を別々の一時 Git repository で初期化し、要求の人手修正なしに `phase=completed` まで順次実行する。
- 3作品合計 USD 5.00、1作品 USD 2.00、論理呼び出し30、writer 本文生成2、所要20分/作品の上限を超える前に安全停止する。
- 各 run 後の `validate`、run/report/checkpoint/hash、Git 作業ツリー、usage/cost、無出力間隔を検査する。
- 実測値と合否、停止理由を秘密なしの Markdown/JSON に記録する。
