# フェーズ017: run コマンド統合

## ゴール

既存の要求解釈、制作ワークフロー、実行永続化、報告、Git 安全機構を `story-pipeline run` へ接続し、1件の要求を安全な開始境界から終了境界まで処理できるようにする。

## 完了条件

- 仕様で定めた順序で前提検査、ロック、接続確認、開始時コミットを行う。
- 決定した制作フェーズを実行し、採用可能な成果物だけを原子的に保存する。
- run、state、報告を終了状態に確定し、管理対象だけを終了時コミットへ含める。
- 終了後の次要求を未コミットで排他的に作成する。
- 正常、確認待ち、失敗、要求なしを API 非依存テストで検証する。
- OpenRouter 統合確認では `deepseek/deepseek-v4-flash:nitro` を使用する。
