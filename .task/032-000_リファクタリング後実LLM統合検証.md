# リファクタリング後実LLM統合検証

## 背景

フェーズ031において、Story Pipeline の全7フェーズ（構想、基礎設定、全体構成、話計画、本文、章改稿、全体改稿）のワークフロー処理を共通のジェネリックエンジン（`story_pipeline/workflow/engine.py`）にリファクタリングし、単体テストによる動作検証を完了した。

## 作業目標

実際の LLM API（OpenRouter: `deepseek/deepseek-v4-flash:nitro`）を用いた統合テスト群を順次実行し、リファクタリング後のワークフローエンジンが実環境において正常に動作すること（プロンプト生成、構造検証、評価・改稿ループ、成果物保全、状態遷移、報告出力）を完全検証・確定する。

## 完了条件

- OpenRouter API を使用した個別フェーズ統合テスト（`concept`, `foundation`, `plotting`, `episode_planning`, `drafting`, `chapter_revision`, `final_revision`）がすべて正常に通過すること。
- `run` コマンド統合テスト（`integration_openrouter_run_command.py`）および3作品連続実行テスト（`integration_openrouter_three_stories.py`）が正常に通過すること。
- リファクタリングに起因する回帰障害が存在しないことを実走行レベルで実証し、結果を記録すること。
