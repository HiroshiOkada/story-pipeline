# 作品状態復旧

## 作業目標

作品プロジェクトの進行状態や実行記録に不整合があり通常の `run` や `migrate-state` で復帰できない場合でも、未コミット情報を Git 履歴へ保全したうえで、既存成果物から状態を再構築し、新しい要求を処理できる待機状態へ戻せるようにする。

## 完了条件

- 復旧前の作業ツリーの変更を独立した Git commit として保全できる。
- 明示的な同意なしに active request や未回答判断を放棄しない。
- 既存成果物を変更せず、制作状態を再構築できる。
- 中断・失敗した run 記録を削除せず監査可能な形で保持する。
- 復旧後に新しい要求を通常の `run` で開始できる。
- 仕様、利用者向け文書、テストが実装と一致する。
